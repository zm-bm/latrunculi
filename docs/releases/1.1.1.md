# Latrunculi 1.1.1 (Unreleased)

## Changes since 1.1.0

- Retuned the existing handcrafted evaluation weights using self-play games.
  Evaluation features and search algorithms are unchanged.
- Added simpler commands under `bin/` for benchmarking, tuning, and OpenBench,
  with a shared Python environment for development tools.
- Reworked the development documentation around a manual build, test, and
  comparison workflow.
- Corrected a late-move-reduction regression test to check full-depth verification
  of an apparent reduced-search cutoff.

## Playing strength

The retuned evaluation passed OpenBench #45 against 1.1.0 after
6,982 games, reaching the acceptance boundary of an SPRT with bounds `[0,3]`
and alpha=beta=0.05. The test used `10+0.1` with speed normalization, one thread,
32 MiB hash, and the `UHO_Lichess_4852_v1.epd` opening book with reversed colors.

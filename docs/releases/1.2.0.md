# Latrunculi 1.2.0

## Changes since 1.1.1

- Added singular extensions and verification multicuts to focus search on
  moves that stand out from their alternatives.
- Improved capture ordering with capture history and deferred losing captures,
  and added pruning of low-gain quiescence captures.
- Disabled transposition-table score cutoffs at principal-variation nodes.
- Unified legal move traversal for ordinary callers, main search, and
  quiescence. Moves are emitted directly into candidate storage, with ordering
  history and node learning kept separate from selection.
- Made recursive search frames and their principal variations explicit, and
  clarified root-result ownership, helper startup, and search control flow.
- Simplified board-state ownership and shared evaluation finalization with
  feature reconstruction.
- Retuned material, piece-square, mobility, and positional evaluation weights
  using 42,000 self-play games from the updated engine.

## Evaluation tuning

The tuning corpus retained 248,914 settled positions across 21,000 opening
groups. Grouped five-fold validation reduced held-out prediction error by
0.11%, with improvement in every fold and no parameter-bound hits.

The tuned evaluation scored **+11.82 Elo, with a nominal 95% interval of
±7.56 Elo**, against the pre-tuning engine at `8b8a06c`. OpenBench #91 was
stopped after 5,000 games from an initial 10,000-game target: 1,798 wins,
1,628 losses, and 1,574 draws. The test used `10+0.1` with DEV speed scaling,
one thread, 32 MiB hash, and paired UHO openings.

This is a descriptive result from an early-stopped test, not a measurement of
the complete release's strength gain over 1.1.1.

## Downloads

The Linux x86-64 binary requires POPCNT and glibc 2.38 or newer. The C++ runtime
is linked statically. The source archive includes the pinned GoogleTest
dependency, so its test build does not require a submodule download.

Build instructions are in the [README](https://github.com/zm-bm/latrunculi#build).
The built-in benchmark for this version reports **7,077,765 nodes**.

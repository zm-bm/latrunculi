# Latrunculi 1.2.0

## Changes since 1.1.1

- Added singular extensions and verification multicuts to focus search on
  moves that stand out from their alternatives.
- Improved capture ordering with capture history and deferred losing captures,
  and added pruning of low-gain quiescence captures.
- Disabled transposition-table score cutoffs at principal-variation nodes.
- Unified legal move traversal for ordinary callers, main search, and
  quiescence. Moves are emitted directly into candidate storage, with ordering
  history and node learning kept separate from selection.
- Made recursive search frames and their principal variations explicit, and
  clarified root-result ownership, helper startup, and search control flow.
- Simplified board-state ownership and shared evaluation finalization with
  feature reconstruction.
- Retuned material, piece-square, mobility, and positional evaluation weights
  using 42,000 self-play games from the updated engine.

### CCRL Blitz estimate

The released [v1.2.0 revision][v1.2.0-revision] completed six OpenBench matches
on November 9, 2026, totaling **12,032 games with no reported crashes or time
losses**. The combined estimate is **approximately 2,950 CCRL Blitz Elo**
(fitted rating: 2,947).

Reference ratings are for the 64-bit, one-CPU versions in the
[CCRL Blitz list][ccrl] computed November 7, 2026. Results are from
Latrunculi's perspective; draws count as half a point.

Engine links identify the tested source revisions. OpenBench test links require
access to the private test server. Drofa's revision adds only a missing
`<cstdint>` include to upstream 3.0.0 so it builds with GCC 15.

Matches ran on an AMD Ryzen 7 2700X with `Threads=1 Hash=128`, no tablebases,
and paired colors from `UHO_Lichess_4852_v1.epd`. Both engines used nominal
`10+0.1` time controls, scaled together by OpenBench's DEV method to
2,050,000 Latrunculi nodes per second. Win adjudication used 400 cp for three
moves; draw adjudication used 10 cp for eight moves after move 40. Each match
had a fixed 2,000-game target; in-flight pairs account for the small overruns.

Each implied rating is the opponent's reference rating plus
`400 × log10(score / (1 − score))`. The combined estimate fits one rating
whose expected total score against the six reference ratings matches the
observed total, weighted by each match's game count.

**This is an estimate from our own tests, not an official CCRL rating.**
The opponent-specific estimates span 2904–2977; that range is not a confidence
interval. CCRL reference uncertainty and differences in matchups, openings,
adjudication, and hardware calibration limit precision. These games were much
shorter than [CCRL's calibrated `120+1` time control][ccrl-conditions]; longer
games could move the estimate in either direction.

## Evaluation tuning

The tuning corpus retained 248,914 settled positions across 21,000 opening
groups. Grouped five-fold validation reduced held-out prediction error by
0.11%, with improvement in every fold and no parameter-bound hits.

## Downloads

The Linux x86-64 binary requires POPCNT and glibc 2.38 or newer. The C++ runtime
is linked statically. The source archive includes the pinned GoogleTest
dependency, so its test build does not require a submodule download.

Build instructions are in the [README](https://github.com/zm-bm/latrunculi#build).
The built-in benchmark for this version reports **7,077,765 nodes**.
